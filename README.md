# EcoSphere

EcoSphere is a simplified ecosystem evolution simulator inspired by evolutionary algorithms and ecological systems.

I built this project to explore how predator and prey populations evolve under environmental pressure using mutation, trait evolution, and population dynamics.

The simulation models:
- plants
- prey
- predators
- evolving traits
- environmental pressure
- food availability
- population changes over generations

## Technologies Used
- Python
- Flask
- JavaScript
- HTML/CSS
- Chart.js

## Features
- Ecosystem population simulation
- Trait mutation system
- Predator/prey fitness calculation
- Multiple environments
- Interactive charts
- Explainable simulation insights
